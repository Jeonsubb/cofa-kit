# 인수인계 문서 작성

결과는 반드시 **저장소 안의 `docs/handoff.md`**에 쓴다(임시 폴더 아님).

## 작성 전 확인
- `git log --oneline`, `git status`, 테스트 실행 결과, `AGENTS.md`, `docs/decisions.md`, `docs/verification.md`를 읽는다.
- 문서에 쓰는 실행 명령은 직접 실행해 동작하는지 확인한다.

## 담을 내용
1. 한 줄 요약: 누구의 어떤 문제를, 무엇으로, 어디까지 해결했나
2. 실행 방법: 설치, 실행(포트·경로), 테스트 명령
3. 구조: 주요 파일과 역할
4. 핵심 흐름: 입력 → 처리 규칙 → 출력
5. 성공 기준 달성 현황과 근거
6. 알려진 한계와 위험: 지점, 문제, 영향, 대응 계획
7. 다음 할 일(우선순위 순)

## 규칙
- 코드에 없는 기능을 적지 않는다. 미완성은 미완성이라고 쓴다.
- 이미 다른 문서에 있는 내용은 경로로 참조하고 반복하지 않는다.
- 실명·이메일·키를 넣지 않는다.
- 새 세션으로 넘길 때는 `AGENTS.md`의 진행 단계와 "알려진 한계 / 다음 할 일"도 함께 갱신한다.
