# 제출 직전 체크리스트

- [ ] 과제 안내의 **필수 파일명·경로**대로 있는가
- [ ] 성공 기준을 하나씩 직접 실행해 확인했는가 (`docs/verification.md`)
- [ ] 테스트를 실행했고 결과를 기록했는가
- [ ] 마지막 변경까지 커밋했는가 (`git status` 깨끗함)
- [ ] 문서 내용이 실제 코드와 일치하는가 (없는 기능을 적지 않았나)
- [ ] 실명·이메일·키 등 민감 정보가 코드·문서·로그에 없는가
- [ ] 알려진 한계를 숨기지 않고 적었는가
- [ ] 에디터 탭이 모두 "저장됨" 상태인가
- [ ] 후속 질문 대비: `docs/decisions.md`를 한 번 읽었는가

## 후속 질문 답변 틀
약점 지점 → 왜 위험한가(파급) → 다음에 무엇을 검증·개선할 것인가
질문의 전제가 실제 구현과 다르면 그 차이를 먼저 밝힌다.
