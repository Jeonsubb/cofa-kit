# 제출 직전 체크리스트

- [ ] 과제 안내의 **필수 파일명·경로**대로 있는가
- [ ] 성공 기준을 하나씩 직접 실행해 확인했는가 (`docs/verification.md`)
- [ ] 탐색·생성 결과를 별도 검사기로 규칙 위반 0건 확인했는가
- [ ] 테스트를 실행했고 결과를 기록했는가
- [ ] 마지막 변경까지 커밋했는가 (`git status` 깨끗함)
- [ ] `docs/architecture.md`, `docs/handoff.md` 범위 현황이 실제 코드와 일치하는가
- [ ] `docs/ai-judgment-log.md`에 수용·수정·폐기 사례가 각각 1건 이상 있는가
- [ ] 실명·이메일·키 등 민감 정보가 코드·문서·로그에 없는가
- [ ] 알려진 한계와 미검증 위험을 숨기지 않고 적었는가
- [ ] 에디터 탭이 모두 "저장됨" 상태인가
- [ ] `$qa-brief`로 `docs/qa-brief.md`를 만들고 읽었는가

## 제출 직전 2~3분에 들고 갈 4가지
1. 핵심 동작과 요청 흐름
2. 확인 방법 (어떤 입력·명령·검사기로, 숫자)
3. AI 산출물에서 수용·수정·폐기한 것과 계기
4. 구현하지 않은 범위·가정·남은 위험

## 답변 틀
- 약점 지점 → 왜 위험한가(파급) → 다음에 무엇을 검증·개선할 것인가
- 질문의 전제가 실제 구현과 다르면 그 차이를 먼저 밝힌다.
- 질문 유형별 틀은 `checklists/questions.md` 참조.
